Jeu du Pendu – Pygame

Un jeu du pendu interactif développé en Python avec Pygame, incluant un menu, des scores, un choix de difficulté avec chronomètre et la possibilité d’ajouter ses propres mots.

 IFonctionnalités:

 Mot aléatoire depuis mots.txt

.Choix de difficulté

1)Facile : 5 minutes

2)Normal : 2 minutes

3)Difficile : 30 secondes

 Nombre d’erreurs limité


 Historique des scores (score.txt)

 Ajout de mots avec gestion d’erreurs

🏠 Icône pour revenir au menu

 Interface graphique avec Pygame

IIFichiers nécessaires:

main.py (script principal)

mots.txt (liste de mots)

score.txt (créé automatiquement)

home.png (icône du menu)
